# Laser strike

Opus in an Ogg container. Originals are in `art/audio-src/laser/`. All four are 3.02 s, uncut, by yodguard (Pixabay).

Each laser plays one at random (never the same twice running), whole: it starts as the beams appear and ends as the
blast fires. The default laser timings (gather 1.8 + pause 0.92 + retract 0.3 s) add up to the tracks' length; if
they are changed in Game Debug, the track plays faster or slower to fit (0.5–2×).
